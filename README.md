# Nirog.com

India's preventive-health hub: 12 free health calculators, the Nirog Score, 16 sourced health guides, trusted health videos, and free health insurance and check-up advice (lead generation), plus donations, contests, careers and partnerships.

- **Live (GitHub Pages):** https://webworksa1.github.io/nirog-com/
- **Domain:** nirog.com (add a `CNAME` file containing `nirog.com` once DNS points to GitHub Pages)
- **Stack:** static HTML/CSS/JS generated by `_build/build.py` (Python 3 + `markdown`). No server needed.
- **Monetization:** Google AdSense (`ca-pub-6620975821265271`, auto ads + `ads.txt`), lead forms, sponsorships, reader support.

## Edit and rebuild
```
pip install markdown
python3 _build/build.py
```
- Guides: `_build/guides/*.md` (front matter + Markdown)
- Videos: `_build/videos.json`
- Calculators: `_build/tools_data.py` (copy) and `assets/js/tools.js` (logic)
- Page copy: `_build/pages.py`
- Payment links and site settings: `assets/js/config.js`

Forms post through FormSubmit; the destination is assembled at runtime and never appears in the markup. The very first submission triggers a one-time activation email.

See `PROMPTS.md` for the business case and phase-wise build prompt, and `RESEARCH.md` for the competitive review.
